# AI Job Assistant

AI Job Assistant is a web application that helps users analyze job descriptions, improve resume bullet points, and generate tailored application materials using AI.

## Features
- Resume bullet point optimization using AI
- Job description analysis
- Tailored application suggestions

## Tech Stack
- Python
- Flask
- OpenAI API

## How It Works
Users input resume text or job descriptions, and the system uses AI models to provide optimization suggestions and improvements.

## Status
Currently under active development as part of a self-employed AI engineering project.
